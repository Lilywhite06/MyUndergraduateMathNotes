# MyUndergraduateMathNotes

本仓库保存了我本科阶段的数学笔记，主要面向机械、电子、自动化等普通工科专业。

内容涵盖高等数学、线性代数、概率论与数理统计、复变函数与积分变换等常见课程。笔记以 **LaTeX** 为主，部分课程提供导出的 PDF 文件，方便在线阅读与复习。

[![Made with LaTeX](https://img.shields.io/badge/Made%20with-LaTeX-008080.svg)](https://www.latex-project.org/)

---

## 🎯 适用范围

- 普通工科专业本科（非数学系）
- 复习考研数学（数学一/二/三）

每个课程目录下通常会包含：

- `notes/`：核心章节笔记
- `exams/`：考试或测验的试题
- `README.md`：该课程的简要说明

## 🚀 使用方式

下载 PDF 文件或 LaTeX 源码本地编译。

推荐安装：

- [TeX Live](https://www.tug.org/texlive/) 或 [MacTeX](https://www.tug.org/mactex/)
- [VS Code](https://github.com/microsoft/vscode) 插件：[LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)

如果你发现笔记中有错误、遗漏或希望补充内容，欢迎参与贡献！
