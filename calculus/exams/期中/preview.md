# 第二学期 高等数学A 期中测试

考试时间：120分钟　　满分：100分

## 一、填空题（每小题4分，共20分）

1. 设 $L: y=2x,\ 0 \le x \le 1$，则 $\int_{L} y \,\mathrm{d}s=\underline{\quad\quad}$。

2. 向量场 $\mathbf{A}=\{y^{2}, xy, xz\}$ 在点 $(1,1,1)$ 处的散度 $\mathrm{div}\mathbf{A}=\underline{\quad\quad}$。

3. 设 $f(u)$ 具有连续导数，$\Sigma$ 是曲面 $y=x^{2}+z^{2}$ 与 $y=8-x^{2}-z^{2}$ 所围立体的表面外侧，则

   $$\iint_{\Sigma} \frac{1}{y} f\left(\frac{x}{y}\right) \mathrm{d}y\mathrm{d}z+\frac{1}{x} f\left(\frac{x}{y}\right) \mathrm{d}z\mathrm{d}x+z^{2}\mathrm{d}x\mathrm{d}y=\underline{\quad\quad}.$$

4. 交换二次积分次序并计算：$\int_{1}^{4} \mathrm{d}x \int_{x}^{4} \frac{1}{x \ln y} \mathrm{d}y=\underline{\quad\quad}$。

5. $\Sigma$ 为平面 $x+y+z=1$ 在第一卦限的部分，则 $\iint_{\Sigma }(x+y+z) \mathrm{d}S=\underline{\quad\quad}$。

## 二、选择题（每小题4分，共20分）

1. 设 $D=\{(x,y)||x|\le \frac{1}{2},|y|\le\frac{1}{2}\}$，$I_{1}=\iint_{D} x \mathrm{d}x\mathrm{d}y,\ I_{2}=\iint_{D} e^{-(x^2+y^2)}\mathrm{d}x\mathrm{d}y,\ I_{3}=\iint_{D} e^{-(x^2+y^2)^2}\mathrm{d}x\mathrm{d}y$，则

   $$\text{(A) } I_{2}<I_{3}<I_{1}\qquad \text{(B) } I_{1}<I_{2}<I_{3}\qquad \text{(C) } I_{3}<I_{1}<I_{2}\qquad \text{(D) } I_{3}<I_{2}<I_{1}$$

2. 极坐标积分 $\int_{0}^{\frac{\pi}{2}} \mathrm{d}\theta \int_{0}^{2 \cos \theta} f(\rho \cos \theta,\rho \sin \theta)\rho \,\mathrm{d}\rho$ 可化为

   $$\text{(A) } \int_{0}^{2} \mathrm{d}x \int_{0}^{\sqrt{2x-x^{2}}} f(x,y)\mathrm{d}y\qquad \text{(B) } \int_{0}^{2} \mathrm{d}x \int_{0}^{\sqrt{2x-x^{2}}} f(x,y)\sqrt{x^2+y^2}\mathrm{d}y$$

   $$\text{(C) } \int_{0}^{1} \mathrm{d}y \int_{1-\sqrt{1-y^{2}}}^{1+\sqrt{1-y^{2}}} f(x,y)\mathrm{d}x\qquad \text{(D) } \int_{0}^{1} \mathrm{d}y \int_{1-\sqrt{1-y^{2}}}^{1+\sqrt{1-y^{2}}} f(x,y)(x^2+y^2)\mathrm{d}x$$

3. 设 $\Sigma$ 为上半球面 $x^{2}+y^{2}+z^{2}=R^{2}(z \ge 0)$，则 $\iint_{\Sigma }(1-x)\mathrm{d}S=$

   $$\text{(A) } 2 \pi R^{2}\qquad \text{(B) } 2\pi\qquad \text{(C) } 4\pi R^2\qquad \text{(D) } 4\pi$$

4. $\Sigma$ 是上半球面 $x^{2}+y^{2}+z^{2}=R^{2}(z\ge0)$，$\Sigma_1$ 是 $\Sigma$ 在第一卦限部分，则

   $$\text{(A) } \iint_{\Sigma} x\mathrm{d}S=4\iint_{\Sigma_1}x\mathrm{d}S\qquad \text{(B) } \iint_{\Sigma} y\mathrm{d}S=4\iint_{\Sigma_1}y\mathrm{d}S$$

   $$\text{(C) } \iint_{\Sigma} z\mathrm{d}S=4\iint_{\Sigma_1}z\mathrm{d}S\qquad \text{(D) } \iint_{\Sigma} xyz\mathrm{d}S=4\iint_{\Sigma_1}xyz\mathrm{d}S$$

5. 光滑有向曲面 $\Sigma:z=z(x,y)$，$P(x,y)$ 偏导连续，则

   $$\text{(A) } \iint_{\Sigma} P\mathrm{d}y\mathrm{d}z=\iint_{\Sigma} P\cdot z_x \mathrm{d}x\mathrm{d}y\qquad \text{(B) } \iint_{\Sigma} P\mathrm{d}y\mathrm{d}z=\iint_{\Sigma} P\cdot (-z_x) \mathrm{d}x\mathrm{d}y$$

   $$\text{(C) } \iint_{\Sigma} P\mathrm{d}y\mathrm{d}z=\iint_{\Sigma} P\cdot z_y \mathrm{d}x\mathrm{d}y\qquad \text{(D) } \iint_{\Sigma} P\mathrm{d}y\mathrm{d}z=\iint_{\Sigma} P\cdot (-z_y) \mathrm{d}x\mathrm{d}y$$

## 三、计算题（每小题7分，共42分）

1. 计算 $\iint_{D}|x-y^{2}| \mathrm{d}x\mathrm{d}y$，$D=\{(x,y)\mid 0\le x\le1,\,0\le y\le1\}$。

2. 计算 $I=\int_{L}(e^{x} \sin y+x) \mathrm{d}x+(e^{x} \cos y+1)\mathrm{d}y$，$L:y=1-|1-x|$，从 $O(0,0)$ 到 $A(2,0)$。

3. 积分 $\int_{L} x y^{2}\mathrm{d}x+y \varphi(x)\mathrm{d}y$ 与路径无关，$\varphi(0)=0$，求 $\varphi(x)$ 并计算 $I=\int_{(0,0)}^{(1,1)} x y^{2}\mathrm{d}x+y \varphi(x)\mathrm{d}y$。

4. 计算 $\iint_{\Sigma }(x+y) \mathrm{d}y\mathrm{d}z+2y \mathrm{d}z\mathrm{d}x+z \mathrm{d}x\mathrm{d}y$，$\Sigma:z=\sqrt{1-x^{2}-y^{2}}$ 上侧。

5. $C: \left\{\begin{array}{l} x^{2}+y^{2}=1 \\ x-y+z=2 \end{array}\right.$，从 $z$ 轴正向看顺时针，用斯托克斯求 $\oint_{C}(z-y)\mathrm{d}x+(x-z)\mathrm{d}y+(x-y)\mathrm{d}z$。

6. 验证 $(2 x \cos y-y^{2} \sin x) \mathrm{d}x+(2 y \cos x-x^{2} \sin y) \mathrm{d}y$ 为全微分，并求原函数 $u(x,y)$。

## 四、计算题（每小题9分，共18分）

1. $\Sigma$ 为 $\left\{\begin{array}{l} x=1-z^{2},\\ y=0\ (x\ge0) \end{array}\right.$ 绕 $x$ 轴旋转曲面，法向与 $x$ 轴正向夹角 $<\frac{\pi}{2}$，计算

   $$I=\iint_{\Sigma }(2 x^{2}-2) \mathrm{d}y \mathrm{d}z+(x^{3}+y^{2}) \mathrm{d}z \mathrm{d}x+(x^{3}+y^{3}) \mathrm{d}x \mathrm{d}y.$$

2. $L$ 为椭圆 $x^2+3y^2=1$ 逆时针，从 $A(-\frac{1}{2},-\frac{1}{2})\to B(\frac{1}{2},\frac{1}{2})$，计算

   $$\int_{L}(e^{x^{2}} \sin x-2 x y) \mathrm{d}x+(6 x-x^{2}-y \cos ^{4} y) \mathrm{d}y.$$

## 附加题（每题10分，共20分）

1. $L:x^2+y^2=a^2(a>0)$ 逆时针，$f(x)>0$ 连续，证明：

   $$\oint_{L} x f(y) \mathrm{d}y-\frac{y}{f(x)} \mathrm{d}x \geq 2 \pi a^{2}.$$

2. $\Sigma:z=1+x^{2}+y^{2}\ (1\le z\le3)$ 下侧，计算

   $$I=\iint_{\Sigma } \frac{(x-3) \mathrm{d}y \mathrm{d}z+(2-y) \mathrm{d}z \mathrm{d}x+(z-1)^{2} \mathrm{d}x \mathrm{d}y}{z-x^{2}-y^{2}}.$$
